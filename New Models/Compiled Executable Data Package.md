# Compiled Executable Data Package

A CEDP is merely an archive file that conforms to the [[Compiled Executable Data Package Specification]] , it's checksum file, and  associated GPG signature files for both the archive and the checksum file.  A package is a total of 4 files.

The checksum file must be generated by producing a sha512 sum against the file.  The name of the checksum file is the name of the archive file with the extension `.sha512` added.

Thus if the archive is `ABC.tgz` then a tar file of archive, checksum, and signature files could be generated as thus:

```
sha512 ABC.tgz > ABC.tgz.sha512
gpg --sign --armore ABC.tgz
gpg --sign --armore ABC.tgz.sha512
tar cfv ABC.cedp ABC.tgz ABC.tgz.sha512 ABC.tgz.sha512.asc ABC.tgz.asc
```

By convention, a file that ends with `.cedp` is expected to be a tar file with 4 entries named and composed as mentioned here.
